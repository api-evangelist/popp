Popp (Popp AI) is an API-first conversation engine for staffing and recruitment firms. It automates high-volume candidate interactions — screening tens of thousands of applicants, collecting and validating right-to-work and certification documents, running AI candidate analysis, auto-scheduling interviews with calendar sync, and re-qualifying dormant candidate databases — through a drag-and-drop workflow builder and a REST API. The platform exposes conversations, campaigns, documents, analysis, scheduling, and multi-step workflows over https://api.joinpopp.com/v1 with API-key authentication, SHA256-signed webhooks across four event categories, and a published remote MCP server for agent access. Backed by Techstars.

**Areas:** Company · Recruiting · Staffing · Hiring · Conversational AI · Automation · Scheduling · Workflows · Webhook · MCP · Agents

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Popp: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
